\# Otopark Yönetim Sistemi (Parking Automation System)



Bu proje, plaka tanıma sistemi ile entegre çalışan, araç giriş-çıkış işlemlerini güvenli ve akıllı bir şekilde yönetmeyi sağlayan kapsamlı bir otomasyon sistemidir.



\## Öne Çıkan Özellikler



\* \*\*Optik Karakter Tanıma (OCR):\*\* Araç plakalarının kameralar veya görseller üzerinden otomatik olarak okunması.

\* \*\*Akıllı Durum Kontrolü:\*\* Otoparkta halihazırda bulunan (içerideki) bir aracın plakası okunduğunda çift kaydı önleyen (duplicate entry prevention) akıllı doğrulama mantığı.

\* \*\*Kapsamlı Yönetim Paneli:\*\* Otopark doluluk oranının, araç giriş-çıkış saatlerinin ve kayıtlı araçların anlık olarak izlenebilmesi.

\* \*\*Güvenli Veri Yönetimi:\*\* Tüm plaka ve zaman verilerinin ilişkisel veri tabanında tutulması.



\## Kullanılan Teknolojiler



\* \*\*Backend:\*\* PHP

\* \*\*Veri Tabanı:\*\* SQL (MySQL/phpMyAdmin)

\* \*\*Görüntü İşleme:\*\* Python, EasyOCR

\* \*\*Frontend:\*\* HTML, CSS, JavaScript
